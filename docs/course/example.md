# 示例课程文档

> 这是一篇示例文章，用来展示写文章的基本格式。以后写新文章时，复制本文件，改掉内容就行。

## 一、标题怎么写

以 `#` 开头的一行就是标题，`#` 越多，标题层级越小：

# 一级标题（每篇文章只有一个，是页面标题）

## 二级标题（大章节）

### 三级标题（小章节）

## 二、正文怎么写

直接写字就是正文段落。注意：**两个段落之间要空一行**，否则它们会连成一段。

这是第二段正文。想让某些字变粗，用两个 `*` 把字包起来，例如 **加粗**。

## 三、列表怎么写

用 `-` 开头的一行就是一个列表项：

- 列表项一
- 列表项二
- 列表项三

## 四、代码怎么写

用三个反引号（键盘左上角数字 1 旁边那个键）把代码包起来，就是一个代码块：

```python
print("你好，世界！")
```

## 五、链接怎么写

用方括号写链接文字，后面紧跟圆括号写网址：

[MkDocs 官方文档](https://www.mkdocs.org)

## 六、提示框怎么写

引用符号 `>` 开头的一段话，会显示成灰色的引用框：

> 这是一句引用，适合放提示或摘要。

## 七、图片怎么写

用 `!` 开头，方括号写说明文字，圆括号写图片路径：
