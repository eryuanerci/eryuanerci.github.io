# 课程总结与建议&教师评价

首先，从成绩的角度来说，这是一门史课
老师上课是听不懂的（**别浪费时间在课堂上**）
但是这门课98上有很多笔记
或者看tww的网课（[【浙江大学】童雯雯--常微分方程_哔哩哔哩_bilibili](https://www.bilibili.com/video/BV1qk4y1R7W8/?spm_id_from=333.337.search-card.all.click&vd_source=589dfa253e160751c222e4fc84ee37a3)）
其实如果是应付考试，只要记住每种ODE的解法即可
可分离变量方程、齐次方程、全微分方程、一阶线性微分方程、伯努利方程、线性微分方程组...
然后每个都对应几个奇怪的方法：常数变易法、降阶法...
**但是！** **期末考试计算量极大，且给分实事求是**

但是从实用的角度来说，这门课还是挺重要的
